# Using GLOSS in the Labs

Since we are going to have some fun with Haskell Game Development (which is kind of a "thing"), we will
need some way to run graphics.

After a lot of consideration, we are going to use [Gloss](https://hackage.haskell.org/package/gloss), which 
advertises itself as "Painless 2D Vector Graphics, animations and simulations" - and actually is.

But, given the current setup of the lap equipment, we need to take a few preparatory steps:

1. Create a new directory, e.g., `awesome` and open a terminal *into* it.
2. In that terminal, type `cabal init`.
3. The above will open an interactive shell session asking various questions about your project's configuration. Make sensible choices and let the initialisation happen - in most cases, the defaults are pretty much fine.
4. Once you have initialised your project, open the `awesome.cabal` file that has been automatically generated by cabal and spot the build-depends
